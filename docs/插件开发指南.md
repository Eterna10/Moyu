# Moyu 插件开发指南

Moyu 预留了插件接口（**插件 API 版本 1**）。插件可以：

- 扩展 Markdown 语法（markdown-it 插件、自定义代码块语言、渲染后处理）
- 注册命令：自动出现在菜单「插件 → 插件名」中，可绑定快捷键
- 在状态栏添加项目、在侧边栏添加面板、弹出提示 / 输入框 / 对话框
- 读写当前文档，监听打开、修改、保存、主题切换等事件，并能在保存前改写内容
- 持久化保存自己的数据

> [!WARNING]
> 插件在编辑器界面中运行，拥有与 Moyu 界面相同的权限（可以读写文档、调用保存等功能）。请只安装你信任的插件。

## 快速开始：Hello World

1. 菜单「插件 → 打开插件目录」（Windows 下通常是 `%APPDATA%\Moyu\plugins`）。
2. 新建文件夹 `hello`，放入下面两个文件。
3. 菜单「插件 → 重新加载插件」，然后在「插件 → 你好世界」中运行命令。

`plugin.json`：

```json
{
  "id": "hello",
  "name": "你好世界",
  "version": "1.0.0",
  "description": "第一个 Moyu 插件",
  "author": "你的名字",
  "main": "main.js",
  "apiVersion": 1
}
```

`main.js`：

```javascript
Moyu.definePlugin({
  activate(ctx) {
    // 1. 命令：出现在「插件 → 你好世界」菜单中
    ctx.commands.register('greet', () => {
      ctx.ui.toast('你好，' + ctx.workspace.getFileName());
    }, { title: '打个招呼', accelerator: 'CmdOrCtrl+Alt+H' });

    // 2. 自定义代码块：```hello 内容 ```
    ctx.markdown.addFence('hello', (code) =>
      `<p>👋 你好，${ctx.utils.escapeHtml(code.trim())}！</p>`);

    // 3. 状态栏：显示当前文档的标题数
    const item = ctx.ui.addStatusItem({ text: '', title: '标题数' });
    const update = () => item.setText('标题 ' + ctx.editor.getHeadings().length);
    ctx.workspace.onDidChange(update);
    ctx.workspace.onDidOpen(update);
    update();
  },
  deactivate() {
    // 可选。通过 ctx 注册的一切（命令、样式、面板、事件……）都会被自动清理
  },
});
```

## 插件结构

```
plugins/
└── my-plugin/
    ├── plugin.json   清单（必需）
    ├── main.js       入口脚本（由 plugin.json 的 main 指定，默认 main.js）
    └── ...           其它资源（图片、额外脚本等）
```

### plugin.json 字段

| 字段 | 必需 | 说明 |
| --- | :---: | --- |
| `id` | ✔ | 唯一标识，只能包含字母、数字、`.` `_` `-`。插件数据、命令 id 都以它为前缀 |
| `name` | | 显示名称（菜单、插件管理页） |
| `version` | | 版本号 |
| `description` | | 描述 |
| `author` | | 作者 |
| `main` | | 入口脚本，相对插件目录，默认 `main.js` |
| `apiVersion` | | 需要的插件 API 版本，默认 `1`；高于 Moyu 支持的版本时不会加载 |

### 插件目录

| 位置 | 说明 |
| --- | --- |
| `<安装目录>/resources/app.asar/plugins`（开发版为 `ZRID/plugins`） | 内置插件 |
| `%APPDATA%\Moyu\plugins` | 用户插件（菜单「插件 → 打开插件目录」） |

同一 id 只加载一次（内置插件优先）。启用 / 停用状态在「偏好设置 → 插件」中切换，立即生效。

## 生命周期

1. Moyu 启动（或「重新加载插件」）时扫描插件目录，按目录名顺序加载已启用的插件。
2. 入口脚本以普通 `<script>` 方式执行，必须在**加载时同步调用** `Moyu.definePlugin({...})`。
3. 宿主调用 `activate(ctx)`；可以是 `async` 函数，但必须在 5 秒内完成。
4. 停用 / 重新加载时调用 `deactivate()`（可选），并**自动撤销**插件通过 `ctx` 注册的所有内容。
5. 任何一个插件出错（脚本语法错误、`activate` 抛出异常、超时）都只会让它自己被标记为「加载失败」，错误信息显示在插件管理页，不影响其它插件和编辑器。

插件会在打开首个文档之前激活，因此语法扩展对首屏渲染即生效。

## API 参考（ctx）

所有返回「可释放对象」的方法都返回 `{ dispose() }`，可以提前手动撤销；插件停用时会自动撤销。

### 基本信息

| 成员 | 说明 |
| --- | --- |
| `ctx.id` / `ctx.manifest` | 插件 id 与清单内容 |
| `ctx.apiVersion` / `ctx.appVersion` | 插件 API 版本、Moyu 版本 |
| `ctx.asset(path)` | 插件目录内文件的 URL（如图片） |
| `ctx.loadScript(path)` | 加载插件目录内的其它脚本，返回 Promise |
| `ctx.onDispose(fn)` | 注册停用时执行的清理函数 |
| `ctx.log(...args)` | 带插件前缀的控制台日志（开发者工具：`Shift+F12`） |

### ctx.commands

| 方法 | 说明 |
| --- | --- |
| `register(id, handler, { title, accelerator })` | 注册命令，出现在「插件 → 插件名」菜单。`accelerator` 使用 Electron 快捷键格式（如 `CmdOrCtrl+Alt+H`）；与内置快捷键或其它插件冲突、或格式非法时会被忽略 |
| `execute(command, ...args)` | 执行命令：内置命令（如 `fmt.bold`、`para.h2`、`file.save`、`view.source`）或插件命令 `plugin:<插件id>:<命令id>` |

### ctx.markdown

| 方法 | 说明 |
| --- | --- |
| `use(plugin, ...options)` | 注册 [markdown-it](https://github.com/markdown-it/markdown-it) 插件 `plugin(md, ...options)`，作用于编辑器渲染与导出 |
| `addFence(lang, render)` | 自定义代码块语言：`render(code, info)` 返回 HTML 字符串；返回 `null` 时按普通代码块处理 |
| `onRender(fn)` | 每次渲染后调用 `fn(rootElement)`，用于 DOM 后处理（会被多次调用，需保证幂等） |
| `addStyle(css)` | **文档样式**：作用于编辑器，并写入导出的 HTML / PDF |
| `parse(text)` | 用 Moyu 的解析器解析，返回 `{ tokens, env }`（`env.headings` 为标题列表） |
| `render(text)` | 渲染为（已净化的）HTML 字符串 |

插件输出的 HTML 会经过 DOMPurify 净化：`<script>`、事件属性等会被移除，SVG、`class`、`style` 属性可正常使用。

### ctx.editor

| 方法 | 说明 |
| --- | --- |
| `getMarkdown()` / `setMarkdown(text)` | 读取 / 整体替换文档（替换可撤销） |
| `getSelection()` | 当前选中的文本（未处于编辑状态时为空字符串） |
| `replaceSelection(text)` / `insertText(text)` | 在光标处插入（替换选中内容） |
| `insertBlock(text, caret)` | 在当前块之后插入新块，`caret` 为光标在新块中的位置 |
| `getHeadings()` | 标题列表 `[{ level, text, id, line }]` |
| `isSourceMode()` | 是否处于源代码模式 |

### ctx.workspace

| 方法 | 说明 |
| --- | --- |
| `getFilePath()` / `getFileName()` / `getBaseDir()` | 当前文档路径（未保存时为 `null`）、显示名、所在目录 |
| `isDirty()` | 是否有未保存的修改 |
| `onDidOpen(fn)` | 打开 / 新建文档后 |
| `onDidChange(fn)` | 内容变化后（约 250ms 防抖） |
| `onWillSave(fn)` | 保存前调用 `fn(text, { filePath })`；**返回字符串则替换要保存的内容**（编辑器内容同步更新） |
| `onDidSave(fn)` | 保存成功后，参数 `{ filePath }` |
| `onThemeChange(fn)` | 切换主题后，参数 `{ name, dark }` |

### ctx.ui

| 方法 | 说明 |
| --- | --- |
| `toast(message, isError)` | 底部提示 |
| `prompt(title, value, placeholder)` | 输入框，返回 `Promise<string \| null>` |
| `showModal(html, onMount)` | 对话框，`onMount(element, close)`；返回 `close` 函数 |
| `addStyle(css)` | **界面样式**（不进入导出文件） |
| `addStatusItem({ text, title, onClick })` | 状态栏项，返回 `{ el, setText, setTitle, setVisible, dispose }` |
| `addSidebarPanel({ id, title, onShow })` | 侧边栏页签，返回 `{ el, show, isVisible, dispose }`；`el` 为面板容器，内容由插件自行渲染 |
| `getTheme()` | 当前主题 `{ name, dark }` |

界面可使用主题 CSS 变量，以自动适配四套主题：`--bg`、`--bg-soft`、`--text`、`--text-soft`、`--muted`、`--border`、`--accent`、`--accent-soft`、`--heading`、`--sidebar-text`、`--font-mono` 等。

### ctx.storage

插件私有的持久化数据（JSON），保存在 `%APPDATA%\Moyu\plugin-data\<id>.json`。

| 方法 | 说明 |
| --- | --- |
| `get(key, defaultValue)` | 读取 |
| `set(key, value)` | 写入（自动延迟保存到磁盘） |
| `delete(key)` / `all()` | 删除 / 读取全部 |

### ctx.utils

| 方法 | 说明 |
| --- | --- |
| `countWords(text)` | 字数统计：`{ total, cjk, words, chars }`（与状态栏一致） |
| `escapeHtml(text)` | HTML 转义 |
| `debounce(fn, ms)` | 防抖 |

## 示例插件

Moyu 自带两个示例插件，源码在 `plugins/` 目录：

### 写作目标（writing-goal）

完整的界面类插件，演示状态栏、侧边栏面板、命令与快捷键、事件、持久化存储：

- 状态栏显示「🎯 今日 356 / 1000」，点击打开侧边栏「统计」面板
- 面板展示今日目标完成度（环形进度）、本次写作时长与速度、当前文档结构统计（字数、段落、标题、图片、链接、代码块、表格、公式、阅读时长）、最近 7 天写作柱状图
- 命令：显示写作统计（`Ctrl+Alt+W`）、设置每日目标、重置今日字数
- 完成目标时弹出祝贺提示；数据按天保存，保留最近 120 天

### 提示块 Callout（callout）

语法扩展类插件，演示 `markdown.use`、`markdown.addStyle`、`editor.insertBlock`：

```markdown
> [!NOTE]
> 说明

> [!TIP]
> 提示

> [!IMPORTANT]
> 重要

> [!WARNING] 可以自定义标题
> 警告

> [!CAUTION]
> 注意
```

命令：插入「说明」提示块（`Ctrl+Alt+N`）等 5 个。

## 调试技巧

- `Shift+F12` 打开开发者工具，查看 `ctx.log()` 输出与报错。
- 修改插件代码后，菜单「插件 → 重新加载插件」即可生效，无需重启 Moyu，当前文档不受影响。
- 加载失败的原因会显示在「偏好设置 → 插件」对应插件的卡片上。
